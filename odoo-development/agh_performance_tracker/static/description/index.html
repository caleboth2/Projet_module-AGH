AGH Performance Tracker (PMS)

Évaluation des performances RH, MK, QA, DEV avec IA Ollama

Fonctionnalités principales

  • Évaluation sur 4 critères objectifs (0-5) : Assiduité, Deadline, Quantité, Qualité
  • Calcul automatique du score Deadline à partir du taux de livraison
  • Résumé IA généré par Ollama (LLM local, avec gestion d'erreur)
  • Niveaux de performance : Top Performer, Bon, Moyen, Insuffisant
  • Vues : formulaire, liste, kanban, graphique, pivot
  • Tableau de bord : Top Performers, Alertes, Synthèse globale
  • Gestion des droits : Utilisateur / Évaluateur / Admin RH
  • Compatible Odoo 18, Ubuntu, Docker
